# Next Steps

That covers the WebSocket API. A few places to go from here:

- **[REST API](../rest/quickstart.md)** — send any command to Lumia over HTTP, including control of individual lights.
- **[MCP Server](../mcp/setup.mdx)** — hand the same capabilities to an AI assistant so it can control Lumia in plain language.
- **[Custom Overlays](../custom-overlays/custom-overlays-documentation.mdx)** — build browser-source widgets that react to the same events.

We would love to see what you build. Anything unclear or buggy in these docs? [Let us know](https://forum.lumiastream.com/dev).
