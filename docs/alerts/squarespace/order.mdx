# Order

- **Alert key:** `squarespace-order`
- **Source:** Squarespace
- **Event list label:** Order
- **Carries alert image:** yes (`extraSettings.contentImage`)

## Default message template

```text
{{username}} purchased {{items}}
```

## Template variables

Use any of these in alert text, TTS, or chat templates. The same names appear under `data.extraSettings.*` when you subscribe via `Overlay.on('alert')`.

| Template variable | Overlay payload field | Description |
| --- | --- | --- |
| `{{username}}` | `data.extraSettings.username` | The username of the sender |
| `{{displayname}}` | `data.extraSettings.displayname` | The display name of the sender |
| `{{items}}` | `data.extraSettings.items` | The items of the alert comma separated, such as shirt, keyblade, chaos emerald, etc. |
| `{{itemsCount}}` | `data.extraSettings.itemsCount` | No description available yet. |
| `{{item}}` | `data.extraSettings.item` | No description available yet. |
| `{{amount}}` | `data.extraSettings.amount` | The amount sent |
| `{{currency}}` | `data.extraSettings.currency` | The currency used |
| `{{currencySymbol}}` | `data.extraSettings.currencySymbol` | The currency symbol used |
| `{{orderNumber}}` | `data.extraSettings.orderNumber` | No description available yet. |
| `{{orderId}}` | `data.extraSettings.orderId` | No description available yet. |
| `{{fulfillmentStatus}}` | `data.extraSettings.fulfillmentStatus` | No description available yet. |
| `{{channel}}` | `data.extraSettings.channel` | No description available yet. |
| `{{contentImage}}` | `data.extraSettings.contentImage` | No description available yet. |
| `{{orderItems}}` | `data.extraSettings.orderItems` | No description available yet. |
| `{{raw}}` | `data.extraSettings.raw` | The raw data that comes in through the platform for the alert. This is useful for custom code when data is needed that we don't provide by default. |

## Variation conditions

Dimensions you can branch on when configuring alert variations:

- `RANDOM`
- `EQUAL_CURRENCY_NUMBER` - Order Amount is equal to
- `GREATER_CURRENCY_NUMBER` - Order Amount is greater than or equal to
- `EQUAL_VARIABLE`
